# LeaveFlow

A Django-based employee leave management system.

## Features

- User registration and login
- Employee management
- Apply for leave
- View leave requests
- Approve or reject leave requests
- Staff dashboard
- Admin dashboard
- Leave status tracking

## Technologies

- Python
- Django
- Django REST Framework
- HTML
- CSS
- SQLite
- Git
- GitHub
